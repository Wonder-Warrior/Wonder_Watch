# WonderWatch Android Client

Dedicated Android application for **WonderWatch**.

## Features
- **Instant Launch & Clean Loading Animation**: Smooth animated startup splash with dark immersion (`#050608`) and fast hardware-accelerated page rendering.
- **Built-in Ad & Popup Shield**: Pre-loaded blocking shield active from first launch with zero manual setup.
- **Fullscreen Video Mode**: Automatic landscape fullscreen player transition with gesture-bar hiding.
- **Account & Sync Ready**: Supports seamless sign-in and watchlist/history synchronization across devices.
- **Android 8.0+ Compatible**: Lightweight APK designed for phones and tablets.
