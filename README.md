# Wonder_Watch 🎬

A sleek, minimalist web-based anime player built for clean streaming and seamless episode navigation.

## Features
- **Embedded Player:** Clean managed stream integration with auto-skip and custom theme matching.
- **Dynamic Episode Switcher:** Jump between episodes instantly without full-page reloads.
- **Responsive Dark UI:** Designed with Tailwind CSS for mobile and desktop screens.
