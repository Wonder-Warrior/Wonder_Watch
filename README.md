## 🚀 Overview
**Wonder_Watch** is a feature-rich, modern anime streaming interface designed to cut out the clutter, intrusive ads, and clunky navigation of mainstream sites. Built with a responsive dark-mode UI, it integrates dynamic catalog searching, automated episode indexing, and a seamless embedded player workflow.

---

## ✨ Planned & Implemented Features
- **Dynamic Catalog Integration:** Search through thousands of titles via MyAnimeList / AniList metadata syncs.
- **Adaptive Stream Engine:** Managed HLS player with multi-track support (**Sub**, **HSub**, and **Dub**).
- **Smart Auto-Skip:** Built-in auto-skip parameters for intros and outros to keep the viewing experience uninterrupted.
- **Persistent Watch History:** Local storage tracking so you never lose your exact progress or timestamp.
- **Responsive Glassmorphism UI:** Tailored layout for seamless usage across desktop monitors and mobile touchscreens.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (Modular ES6+)
- **Player Layer:** Zokoanime Embed API (`postMessage` event listeners for progress and state handling)
- **Hosting & CI/CD:** Vercel / Netlify with automated GitHub deployment
